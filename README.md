# LangGraph-Chatbot
A Python-based AI chatbot built with LangGraph and Streamlit. The project includes conversational workflows, database integration for chat history, threaded execution, and real-time streaming responses. It explores how to connect AI backend logic with an interactive frontend and manage conversations efficiently.

**About this project**

This project is a Python-based AI chatbot that I built to explore how modern conversational AI applications work. It uses LangGraph to manage the chatbot's workflow and Streamlit to provide a simple and interactive user interface.

The project includes different versions of the chatbot, **including database integration for saving conversations, chat history and threads, streaming responses, and threaded execution**. I also experimented with connecting the frontend and backend, managing conversations, and testing different chatbot functionalities.

Overall, this project helped me understand how to build an AI chatbot from the backend logic to the user interface, while working with LangGraph, Streamlit, databases, threading, and real-time AI responses.
